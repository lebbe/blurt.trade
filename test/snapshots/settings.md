## Sessions

You're logged in on 2 browsers or devices.

Send `POST /api/logout-everywhere` to log out everywhere, this client included.
Other devices are logged out within 5 minutes.

## Bots

Bots are shown: send `POST /api/hide-bots` with
`hideBots=on` to hide them. Bots you follow always show.

You run 0 bots: see [Your bots](</settings/bots>).

## JavaScript

Everything works without JavaScript: every page is plain HTML and every button is an ordinary form. A little JavaScript, only from blurt.trade itself, can make some things smoother. It is optional: turned off, not a single script is sent.

JavaScript is **off** for your account, on every device. Send `POST /api/javascript` as a form or as JSON with `javascript=on` to turn it on.
