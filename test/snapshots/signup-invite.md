# Create a profile

[Back to blurt.trade](</>)

blurt.trade is invite-only right now. You need an invite code from someone who's already
here to sign up.

Send `POST /signup` as a form or as JSON with `username` (letters, numbers and `_`), `password` (at least 8 characters) and `inviteCode`(yours: `ABCD-EFGH-JKLM`).

Keep your password safe, e.g. in a password manager. We don't take an email address, so there's no password reset: a lost password can't be recovered, and neither can the account.
